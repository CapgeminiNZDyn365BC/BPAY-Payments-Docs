BPAY Payments is a comprehensive solution to generate a BPAY Batch file – a single file containing multiple BPAY transactions. The BPAY Batch file is uploaded afterwards by the client via Bank Online Portal for validation. It is client’s responsibility to open a Bank Online Portal account.

BPAY Payments functionality has been developed to generate BPAY Batch file according to the specifications of the following banks:

* Bendigo Bank
* Commonwealth Bank (CBA)

The information in this document will guide the user how to create and download a BPAY file.

To learn more about this app, use the navigation pane or click [Getting Started](getting-started.md).
