We've simplified the setup process but there are still a few things to prepare in your system before you make your first BPAY file export. You'll find everything you need to know in the Setup section, but here's a summary of the steps needed.

* The bank account you wish to pay from must have a BPAY Bank Payment Format and BPAY Payment Bank Code.
* You need to make sure that the vendors you want to pay have BPAY Payment set to True and a Preferred BPAY Account Code set.
* You'll need to assign some new permission sets to your users so they can use the app.

## Supported File Formats

We currently support the following Australian bank file formats:

* Bendigo Bank
* Commonwealth Bank (CBA)

!!! info
    If your Australian bank isn't supported, drop us a line and we'll see if we can add it in a future release.
